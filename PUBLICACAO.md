# Sports Hub — primeira publicação web

Este repositório é independente do FORJA e do calendário de cinema.

## Publicar no GitHub Pages

Abra **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**, escolha `main` e `/(root)`, clique em **Save**. Aguarde o link de publicação que o próprio GitHub mostra. A URL tende a ser `https://antoniocarlosguerinodelima-hash.github.io/Sports-hub/`.

## Recursos neste primeiro teste web

- Interface escura com neon lima e azul, inspirada no design aprovado.
- Jogadores, partidas individuais melhor de 3 sets, ranking ELO com K=32, edição e exclusão de resultados.
- Scout por superfícies, confrontos e aproveitamento; troféus e retrospectiva simplificada.
- Registro simples de treinos e exportação/importação JSON.
- Salvamento local no próprio navegador; dados fictícios até clicar em **Começar com meus dados**.

## Limites importantes

Esta publicação é um **protótipo web simplificado**, não contém o código completo do pacote ZIP v0.1 produzido anteriormente. Ainda não há Supabase, autenticação, duplas, sincronização multiaparelhos, backup na nuvem, nem alertas push. Faça exportações regulares, não insira dados sensíveis e não use como arquivo permanente.

Nenhum arquivo foi adicionado ao repositório do calendário de cinema nem ao FORJA.
